# Hospital Patient Data Analytics

This project is a complete data analytics portfolio project focusing on hospital patient data. It demonstrates skills in data cleaning, exploratory data analysis (EDA), visualization, and building interactive dashboards using Python, Pandas, Matplotlib, Plotly, and Streamlit.

## Folder Structure
```
hospital-data-analytics/
├── data/
│     └── hospital_patient_data.csv
├── notebooks/
│     └── eda_analysis.ipynb
├── dashboard/
│     └── app.py
├── src/
│     ├── data_cleaning.py
│     └── visualization.py
├── requirements.txt
└── README.md
```

## Setup Instructions

1. **Clone the repository** (if applicable) and navigate to the project folder.
   ```bash
   cd hospital-data-analytics
   ```

2. **Install dependencies**. It's recommended to use a virtual environment.
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Streamlit Dashboard**:
   ```bash
   streamlit run dashboard/app.py
   ```

4. **Explore the Jupyter Notebook**:
   ```bash
   jupyter notebook notebooks/eda_analysis.ipynb
   ```

## Tasks Completed
- Data Cleaning: Handled missing values, formatted dates, and removed duplicates.
- EDA: Analyzed patient demographics, disease frequencies, and department distributions.
- Visualization: Created bar charts, pie charts, heatmaps, and time-series plots.
- Dashboard: Built an interactive Streamlit app to filter and explore the data.
